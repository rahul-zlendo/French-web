# Zlendo Realty — Focused Campaign Kit

Prepared 6 October 2026. Sources: user-supplied product and commercial details, official public product pages, and the implementation checks listed in the verification report. This is an initial sales motion, not a CRM opportunity or a completed customer evaluation.

## Audience and positioning

Focus on small architecture practices, interior studios and builders with a current residential client presentation. Start with Morocco and Mauritius. Keep Spain as a later, small test using the deferred Spanish page. Qualify firms by workflow need and willingness to assign an integration owner; a firm needing only a standalone design tool may not be an API fit.

Lead with one problem: turning a 2D plan into presentation visuals the client can understand. Suggested positioning: “Explorez une API pour passer du plan 2D à la présentation 3D de votre projet.” The three benefits are demonstration hypotheses, not proven outcomes. Avoid unsupported “faster”, “more accurate” and ROI claims.

Both [Coohom](https://open.coohom.com/) and [Planner 5D](https://planner5d.com/business/api-integrations) have official API offerings. API availability alone is not a defensible differentiator. Test Zlendo's fit on representative plans, required outputs, integration effort and total usage cost. No superiority claim is made.

## Qualification and evaluation

1. Capture country, activity, firm, work email, monthly project volume, current tools and presentation need. The form records campaign UTM fields when provided.
2. Review fit: actual client-presentation project, representative input, expected output, decision-maker, integration owner and timing.
3. Run a live demo. Use a sample plan the firm is authorized to share; remove client-identifying material where possible. Agree the sample preparation burden in advance.
4. If the demo fits, agree evaluation terms, one input plan, desired outputs and acceptance criteria. Trial duration and quotas are deliberately uncommitted until the founder specifies them.
5. Evaluate conversion suitability, usefulness of presentation outputs, API fit and cost. Record failures and manual corrections as well as successes.
6. Close the evaluation with the buyer and integration owner. Decide whether to proceed, revise the scope or decline. Do not treat a form submission as a qualified opportunity.

Measure: qualified conversations, demos held, evaluations agreed, evaluations completed and next commercial step. Track Morocco, Mauritius and later Spain separately. Suggested qualified-conversation definition: target firm + concrete project + relevant output need + access to a buyer or implementation owner. Budget and conversion targets remain TBD; no invented performance goals are used.
